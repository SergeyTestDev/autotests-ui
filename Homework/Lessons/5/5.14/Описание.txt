В рамках данного задания закрепим написание CSS локаторов для вложенных элементов. Необходимо в поле CSS написать корректные стили вместо wrong.style

    Первый заголовок должен иметь стиль color со значением green
    Второй заголовок должен иметь стиль color со значением orange
    Третий заголовок должен иметь стиль color со значением red


Важно:

    Данное задание ориентировано на практику написания CSS локаторов для вложенных элементов
    В поле HTML ничего изменять/редактировать не нужно
    Работать нужно только с полем CSS
    Вместо неправильных локаторов wrong.style необходимо написать корректные локаторы, чтобы выполнились условия
